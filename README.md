# Calculadora

Projeto de uma calculadora desenvolvida para praticar lógica de programação, manipulação do DOM e operações matemáticas básicas utilizando tecnologias web.

## 🚀 Demonstração

Este projeto simula uma calculadora funcional, permitindo realizar cálculos de forma simples e rápida diretamente no navegador.

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  

## 📌 Funcionalidades

- Adição  
- Subtração  
- Multiplicação  
- Divisão  
- Limpar visor  
- Apagar último número  
- Suporte a números decimais  
- Interface responsiva
